## 👋 About Me

I am an **IT Support Specialist** and **Junior Systems Administrator** based in **Los Angeles, California**. I troubleshoot endpoints, user accounts, business applications, network connectivity, and cloud-based services while building practical automation and documentation that make support work faster and more consistent.

- 🖥️ Support Windows environments, end users, hardware, software, printers, and peripherals
- 🗂️ Work with Active Directory, Microsoft 365, identity management, permissions, and account administration
- 🎫 Handle technical support workflows using ticketing, documentation, and remote-support tools
- 🌐 Troubleshoot TCP/IP, DNS, DHCP, VPN, Wi-Fi, LAN/WAN, VLAN, and firewall-related issues
- ⚡ Automate repetitive support and administration tasks with PowerShell, Bash, and command-line tools
- ☁️ Work with cloud, virtualization, web infrastructure, and deployment platforms
- 🌍 Fluent in **English, Uzbek, Russian, and Turkish**

> **Current focus:** Advancing my Windows Server, Group Policy, networking, cloud, and cybersecurity skills while publishing useful support tools and technical documentation.
